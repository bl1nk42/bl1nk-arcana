# /prd — Check Feature in PRD

Verify a feature exists in PDR.md before implementing.

## Usage

```
/prd check <feature_name>
/prd list [section]
```

## Examples

```
/prd check "Element System"
/prd list "Core Game Systems"
```

## Output

Shows: Section, Status (Defined/Not in PRD), Reference links to GDD/CLASS_TREE/SKILL_SYSTEM/WEAPON_SYSTEM
